1. CHECK THE MACHINE IS QUIET
-----------------------------

    uptime

Load should be low single digits. If something else is hammering the box the
suite takes 30 minutes instead of 9. It no longer produces false failures,
but it is worth knowing before you wait.


2. REBUILD THE VENV IF IT DID NOT SURVIVE
-----------------------------------------

    cd ~/PycharmProjects/prama
    uv sync --extra dev

Only if `prama --version` fails. The interpreter is pinned to 3.13 in
.python-version and lives under ~/.local/share/uv/python, not /usr/bin, so a
reboot should not have touched it.


3. CONFIRM THE GATE
-------------------

    python3 scripts/sync_test_counts.py --write

This IS the gate. It runs the whole suite itself and refuses to write a
number from a red run, so a clean exit means green. Do not run `pytest -q`
first as well — that runs everything twice and costs ~18 minutes a batch.

Expect: 5,182 passed, 96 skipped, 2 xfailed.
If the count differs but the run is green, that is fine — it means tests were
added; the script rewrites README.md to match.
