What is Prama?

Prama is a business-owned, evidence-first data quality control plane: the business declares what its data must be, Prama derives the controls, runs them where the data lives, and keeps evidence an auditor can verify without Prama installed.

pramā (Sanskrit प्रमा) means valid knowledge: a cognition that is both true and arrived at by a reliable means. Its companion pramāṇa is the instrument by which valid knowledge is obtained. Prama is that instrument for an organisation's data: it does not decide what is true, it keeps the record of how anybody knows.

Built for data owners, stewards and control functions in regulated firms, where "the dashboard was green" is not an answer an examiner accepts.

Honest limits

Stated so nobody has to discover them.

  • No reference customers yet, and no competitor has been benchmarked against Prama; the external baselines are named and not run.
  • Console single sign-on is not wired: OIDC ID tokens are verified, no sign-in flow uses them, there is no MFA, and there are four built-in roles.
  • Snowflake has never run against an account, several JDBC dialects are code-complete but unverified, and there is no ODBC connector.
  • ETL export shapes for lineage are configurable and unverified against real exports; mainframe code, DataStage, Talend, Ab Initio and SAS are out of scope.
  • Catalog write-back has not run against a live Collibra, Alation or DataHub.
  • An air-gapped install with a local model has not been verified end to end, and no screen-reader pass has been done.
Competitive landscape

Catalogs know what data means without checking it; lineage tools know where it came from without measuring it; observability tools notice change without being able to prove anything; DQ suites check it without the owner's words; reconciliation products agree two systems in isolation. Prama keeps one record that joins them for the question each is hired for and none completes: can I trust this number, and prove it?

It is not a catalog, a lineage scanner or a mastering product, by design. It sits beside them, imports what they know, and executes and evidences the controls.
