## Rebuilding the diagrams

```bash
python tools/medium/diagrams.py            # SVG and PNG into docs/publications/medium/img/ (needs Inkscape)
python tools/medium/diagrams.py --check    # audit only
```

The generator audits what Inkscape actually lays out, not an estimate. It reports text printed
over text, text escaping the box it belongs to, and anything leaving the canvas. The first
build found nine such issues, all fixed before the images were committed.
`tests/docs/test_medium.py` checks that every image the article uses exists, and runs the
audit wherever Inkscape is installed.

## Publishing on Medium

Medium does not import Markdown tables or relative images, so it takes a few manual steps:

1. **Text:** paste the article section by section. Headings, bold, italics, quotes and code
   blocks survive a paste from a rendered Markdown view.
2. **Images:** upload each `img/NN-*.png` where the article references it, and use the italic
   line beneath it as the caption.
3. **Tables:** Medium has no tables. Paste each as a code block, or as a screenshot of the
   rendered table.
4. **Code:** use Medium's code block (triple back-tick) for the PQL, SQL and Python examples.

Every figure in the article comes from a test, `prama bench run --seed 42`, or a case study's
own run. If one of those changes, change the article in the same commit.
